# Project Overview
This project features heavily optimized, modded configurations designed to elevate the general gameplay experience. The modpack is distributed in the `.mrpack` format and includes an `overrides` folder containing all necessary files.

### 🛠️ Installation Instructions
* **Manual Installation Required:** Do not process this file through automated ZIP generators. Instead, manually rename the file extension to `.zip`, extract it, and copy the entire contents of the `overrides` folder directly into your instance directory.
* **Pre-Configured Settings:** Please note that the `overrides` folder includes my personal custom configurations and settings rather than vanilla defaults. This is because I could not be bothered to make a new instance just for sharing my modpack.

### 📅 Upcoming Updates
A link to the official GitHub repository will be provided shortly. Once live, please use the **GitHub Issues tab** to submit any mod requests. I will also share the custom generation tool used to build this pack, which serves as a lightweight alternative if you experience similar issues to me booting the Modrinth desktop application.
